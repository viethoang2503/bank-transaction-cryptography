# TBA Midterm: Master Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement the sub-plans task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây hệ thống demo TBA 4 chế độ, chạy đánh giá bảo mật tái lập được, và nộp report PDF đúng yêu cầu trong 10 ngày với 6 người.

**Architecture:** Lõi mật mã `tba_core` dùng chung; server FastAPI + SQLite; authenticator web trên điện thoại; addon mitmproxy giả lập MitB; package `evaluation` chạy kịch bản S1-S13 trên `VirtualPhone` và sinh bảng/hình cho report.

**Tech Stack:** Python 3.11+, cryptography, FastAPI, Jinja2, SQLite, segno, pytest, matplotlib, mitmproxy (riêng), JavaScript ES modules + Web Crypto, jsQR, Node ≥ 20 (chỉ để test JS), LaTeX/Overleaf.

**Spec:** `docs/superpowers/specs/2026-11-06-tba-midterm-design.md` · **Architecture:** `docs/architecture.md`

## Global Constraints

- Python ≥ 3.11; Node ≥ 20 cho `node --test`.
- Chế độ hợp lệ: `baseline`, `hmac`, `sig`, `sig_blind`.
- Domain tag: `b"TBA-HMAC-v1"` và `b"TBA-SIG-v1"`, nối với canonical bằng một byte `0x00`.
- Tiền tố QR: `tba1:` (giao dịch), `tbaenroll1:` (đăng ký).
- OTP: `hmac` 8 chữ số, `baseline` 6 chữ số; TOTP bước 30 s, cửa sổ ±1; tối đa 3 lần thử; hạn giao dịch 120 s; hạn token đăng ký 300 s.
- Giao diện (web, app) bằng tiếng Anh. Report bằng tiếng Anh.
- Không bao giờ dùng giao dịch do client gửi để xác minh; luôn dựng lại từ `transactions.canonical`.
- Endpoint `/api/device/confirm` không bao giờ trả 5xx với input xấu.
